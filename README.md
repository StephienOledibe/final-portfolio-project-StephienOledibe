# Portfolio Final Project (CSC-2001)

This is my final project website — a simple, responsive personal portfolio built with HTML, CSS, and JavaScript. It includes a **home page**, **projects page** (with 2 project cards), and a **contact page** with a functional form. The site also features an **inspirational quote API** and smooth animations.

🌐 **Live Site:** [https://stephienoledibe.github.io/final-portfolio-project-StephienOledibe/](https://stephienoledibe.github.io/final-portfolio-project-StephienOledibe/)

## Features
- Home page with profile, bio, and inspirational quote API
- Projects page with cards and animations
- Contact page with working AJAX form
- Theme toggle (light/dark)
- Fully responsive design

## Deploy (GitHub Pages)
1. **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main`, Folder: `/ (root)`
2. Wait ~1 min. Your site will be live at the URL above.
